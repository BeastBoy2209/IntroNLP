# Automated Content Moderation

Проект по автоматической модерации текстовых сообщений для курса Intro to NLP.

## Авторы
- **Тимур Харитонов**
- **Даниал Каиров**

## Описание проекта
Цель проекта — автоматизация обнаружения нежелательного контента (токсичность, спам) в текстовых сообщениях, снижение нагрузки на ручную модерацию и повышение безопасности онлайн-общения.

## Стек технологий
- **Язык программирования:** Python
- **Обработка данных & NLP:** Pandas, NumPy, Scikit-learn, NLTK / SpaCy
- **Моделирование:** Logistic Regression (baseline), Naive Bayes, Linear SVM
- **API & Бэкенд:** FastAPI, Uvicorn
- **Демо-интерфейс:** Streamlit
- **Интеграция:** Telegram Bot API (aiogram / python-telegram-bot)
